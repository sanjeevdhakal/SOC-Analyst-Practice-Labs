# Security Operations Center (SOC) Analyst Practical Portfolio

Welcome to my security investigation and threat hunting portfolio. This repository is decoupled from my infrastructure documentation and focuses entirely on logging actionable defensive alerts, analyzing telemetry, mapping adversary behavior to the MITRE ATT&CK framework, and writing incident triage reports.

---

## 🚀 Active Technical Objectives
1.  **MITRE ATT&CK Mapping:** Simulating adversary techniques using Kali Linux and generating custom detection logic in my SIEM.
2.  **Phishing Ingestion & Triage:** Safe analysis of raw `.eml`/`.msg` artifacts, extracting indicators of compromise (IOCs), and parsing mail gateway logs.
3.  **Endpoint Telemetry Analysis:** Investigating operating system event IDs (Linux Syslog & Windows Security Logs) inside an active SIEM/EDR engine.
